# VEngine

VEngine is a cross-platform game engine and editor written in modern C++.

## Vision

Build a modern, modular game engine while learning how real engines are designed.

## Goals

- Learn modern C++
- Learn CMake 
- Build my own math library
- Learn computer graphics
- Build an editor with Dear ImGui
- Support Windows, Linux and macOS
